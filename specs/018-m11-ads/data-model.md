# Data Model: Ads Integration (M11)

M11 keeps little state of its own. Almost everything it decides from is already on the phone: the
operation log, the cached bootstrap, the first session and the tunables. What is new:

## Drift schema 6 (from 5)

One migration step, `from5To6`, generated by `make-migrations`, with its schema export and its
migration tests.

| Table | Change | Why |
| --- | --- | --- |
| `ledger_ops` | `op_type`'s check gains `ad_reward_seen` (a table rebuild, as M10's step did) | R13 |
| `trip_intent` | `kind`'s check gains `ad_reward` (rebuild) | R8: the ad «زحمة»'s outbox row |
| `server_info` | new nullable text column `ads`: the bootstrap's `ads` block as canonical JSON | R11 |

Writers don't change: the economy store writes `ledger_ops`, the trip records write `trip_intent`,
and the account store writes `server_info`.

## Operation `ad_reward_seen` (R13)

| Field | Value |
| --- | --- |
| `op_type` | `ad_reward_seen` |
| `payload` | `{"nonce": "<uuid>"}`, the piggy reward's reference |
| deltas | none; `reason` and `ref` null |
| projection | unchanged; the fold skips it |
| local refusal | `already_recorded` when a row with the same nonce exists (any `sync_status`) |
| server | always `accepted`, `grants: []` (B07 contracts/api.md) |
| rollback toast | never (it changes nothing visible) |

## `AdsBlock` (wire, the bootstrap's `ads`)

```text
AdsBlock
  piggyAvailable: bool              ← ads.morning_piggy.available
  unseen: List<PiggyGrant>          ← ads.morning_piggy.unseen (≤ 5, newest first)

PiggyGrant
  nonce: String (UUID)
  jenehat: int
  bonat: int
  grantedAtMs: int
```

A bootstrap without the block (a server older than B07) parses as `available: false`, `unseen: []`.
`ServerInfo` exposes it as `ads`, read through `adsBlockProvider`.

## `PiggyLookup` (wire, `GET /v1/ads/rewards/{nonce}`)

```text
PiggyLookup = Granted(jenehat, bonat, grantedAtMs)   # 200 status granted; `wallet` read, not applied (R12)
            | Refused(reason)                        # 200 status refused: cap_reached | not_server_placement | expired
            | NotYet                                 # 404 not_found, a timeout or a network error
```

## Device preferences (`SettingsStore`, R10)

| Key | Type | Written | Meaning |
| --- | --- | --- | --- |
| `pref.ads_last_interstitial_trip` | int (default 0) | when an interstitial closes | the trip count when it showed |
| `pref.ads_last_rewarded_trip` | int (default 0) | when any rewarded ad pays, the piggy included | the trip count then |
| `pref.ads_piggy_attempted_day` | game day (none by default) | when the piggy's ad pays | the banner stays hidden that day, relaunch included |

Only `AdsService` writes them. They are pacing, not game state: no sync, no backup concern, and a
fresh install starts at 0.

## In memory (`AdsService`, `PiggyService`)

```text
PlacementReadiness (per placement)
  state: notLoaded | loading | ready(loadedAtMs) | failed(retryAtMs, attempt)
  # ready expires 55 min after loadedAtMs (R16)

ConsentState
  ranThisLaunch: bool
  canRequestAds: bool

PiggyAttempt (one per game day)
  gameDay: String (YYYY-MM-DD)
  reference: String (UUIDv4)
  state: watching | asking(attempt 1..3) | granted(PiggyGrant) | refused(reason) | gaveUp
```

`PiggyAttempt` moves `watching → asking(1) → asking(2) → asking(3) → granted | refused | gaveUp`.
An ad closed without a reward drops the attempt, and the banner stays. After `asking(1)`, the banner
hides for that game day.

## Derived values (no storage)

| Value | From |
| --- | --- |
| `gameDayOf(trustedMs)` | Cairo's date, Egypt's DST rule (R9) |
| refill ads today | `Economy.adRewardsOn(fuelRefill, gameDay)`: non-rejected `ad_reward` rows with that placement and day |
| trips | `Economy.tripStarts()`: the count of `trip_start` rows |
| tutorial trip index | `TutorialPlan` (M07): the finished trip's index in the tutorial, or none |
| entitlements | `entitlementsProvider` (M06): `removeAds`, `noInterstitials` |
| online | `isOnlineProvider` (M06) |

## Rules (pure, `lib/core/ads/domain/`, tested first)

```text
adOffer(placement, facts) → Offered | NotReady | LimitReached | NeedsNetwork | Hidden
  Hidden        the placement doesn't apply: result_double on a failed, unpaid, already doubled, or
                tutorial-trip-1-or-2 result; trip_revive when already revived or not revivable;
                traffic_jam with stock left or one ad used this trip; any placement but
                result_double before the tutorial is done; fuel_refill with a full tank;
                morning_piggy when the banner's rule (R11) fails
  NeedsNetwork  offline
  LimitReached  fuel_refill: refill ads today ≥ ads_fuel_refill_daily_cap
  NotReady      no loaded ad
  Offered       otherwise

interstitialDue(trips, lastInterstitialAt, lastRewardedAt, tutorialDone, removeAds,
                noInterstitials, online, loaded, grace, everyN) → bool   (R10)

gameDayOf(trustedMs) → 'YYYY-MM-DD'                                       (R9)

piggyPlan → waits [1000, 2000, 4000] ms: asks at 1 s, 3 s, 7 s after the reward   (R12)
```
